# Mine projekter 👋

Jeg bygger apps og værktøjer fra København: mentalisme-rekvisitter, spil, Minecraft-værktøjer og lidt hverdagsnyttigt. Mest PWA'er i vanilla JS og React, plus lidt SwiftUI og Rust.

## 🎩 Mentalisme og magi
Apps der ser helt almindelige ud for tilskueren, men har en hemmelig effekt.

| App | Hvad den gør |
|---|---|
| [ClockPlus](https://github.com/Thyxo/ClockPlus) | Falsk iPhone-låseskærm, hvor klokken i hemmelighed kan stilles |
| [Calcplus](https://github.com/Thyxo/Calcplus) | Lommeregner hvor `=` giver et forudbestemt tal |
| [Stopwatchplus](https://github.com/Thyxo/Stopwatchplus) | Stopur der stopper på et forudbestemt tal |
| [NoterPlus](https://github.com/Thyxo/NoterPlus) | Falsk Noter-app med forudsigelse, koblet til Calcplus |
| [FakeGoogle](https://github.com/Thyxo/FakeGoogle) | Falsk Google-forside der opfanger det tilskueren søger |
| [Ereolen](https://github.com/Thyxo/Ereolen) | E-bogsapp med H.C. Andersen-eventyr som rekvisit |
| [digital-change (KameraPlus)](https://github.com/Thyxo/digital-change) | Kamera-app med skjult kortskift (SwiftUI) |
| [Lie-Detector (MindTrace)](https://github.com/Thyxo/Lie-Detector) | Løgnedetektor med skjult vibration (SwiftUI) |
| [MemdeckPlus](https://github.com/Thyxo/MemdeckPlus) | Lær og brug memorerede kortspil (React + TypeScript) |
| [ForceApp](https://github.com/Thyxo/ForceApp) | Force-app |
